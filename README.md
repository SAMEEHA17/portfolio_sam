# Portfolio Website

Welcome to my personal portfolio website! This project showcases my skills, projects, and achievements in web development and programming.

---

## 🌟 Features

- **Responsive Design:** Works seamlessly on desktop, tablet, and mobile devices.
- **Interactive Sections:** Smooth scrolling and animations for a modern experience.
- **Projects & Achievements:** Highlights my academic and professional accomplishments.
- **Contact Form:** Integrated with [Formspree](https://formspree.io) to receive messages directly via email.

---

## 🛠️ Technologies Used

- **HTML5:** Structure and content of the website.
- **CSS3:** Styling, responsive design, and animations.
- **JavaScript:** Interactive features and form validation.
- **Formspree:** Backend-free contact form functionality.
